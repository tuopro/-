# CNDES 德赛报价小程序商务高级 UI 统一设计

## 背景

当前小程序已经具备完整业务功能：客户申请、审核中状态、管理员审核、线槽规格选择、数量输入、报价清单、折扣、含税/不含税展示、快运与物流自提运费、复制报价单、生成报价单图片。此次只做 UI 美观优化，不改变报价计算、审核权限、云函数、产品与运费数据规则。

用户确认采用“商务高级型”方向：突出 CNDES 德赛品牌，偏 Apple 风格的简洁、高级、清晰。

## 设计目标

1. 所有页面统一为商务高级风格，避免报价页、结果页、申请页、后台页视觉割裂。
2. 保留现有功能和操作路径，降低误改业务逻辑的风险。
3. 强化品牌识别：CNDES 德赛、PVC 线槽、厂家报价工具。
4. 提升报价效率：规格选择、米数输入、清单、最终价格仍然一眼可读。
5. 提升客户转发质感：报价结果页和图片生成入口要更像正式报价单。

## 视觉语言

- 背景：使用浅灰到浅蓝灰的柔和渐变，保持 Apple 风格的干净质感。
- 卡片：白色或轻微半透明白色，圆角加大，阴影更轻更柔。
- 主色：使用接近 Apple 蓝的品牌蓝，统一按钮、选中态、价格重点。
- 辅助色：绿色只用于物流、自提、审核通过等正向状态；红色只用于拒绝、必填、删除等风险动作。
- 字体层级：标题更重，说明文字更浅，价格数字更大更醒目。
- 图标：减少 emoji 的装饰感，优先使用文字、字母标识、简洁状态符号；必要图标保持克制。

## 页面设计

### 全局

新增统一的设计基础样式：

- 页面背景、品牌色、文字色、卡片、按钮、输入框、状态标签统一。
- 通用卡片从旧版强边框和重分割线，调整为柔和圆角和轻阴影。
- 表格类信息保留原结构，但分割线更浅，标题和金额更清晰。

### 报价页

报价页保留原有流程：

1. 选择高度。
2. 选择宽度。
3. 选择齿形。
4. 选择颜色。
5. 输入米数。
6. 加入报价清单。
7. 设置折扣、运费、地址。
8. 查看报价结果。

UI 调整：

- 顶部改为品牌头部：`CNDES 德赛`、`PVC 线槽快速报价`、简短说明。
- 管理员入口保留，但视觉上改成轻量圆角图标按钮。
- 当前规格信息改为重点信息卡，突出规格、单价、整箱米数。
- 规格按钮改成 Apple 风格胶囊按钮，选中态为品牌蓝。
- 输入米数区域更像表单行，减少边框感。
- 报价清单和报价结果保留，但金额列更突出，删除按钮更克制。
- 含运费、运输方式、地址选择保持原逻辑，视觉统一为设置项列表。

### 报价结果页

结果页保留原功能：

- 展示产品明细。
- 展示折扣前后产品总价。
- 展示不含税总价。
- 展示总重量、总件数。
- 展示快运和物流自提价格。
- 复制报价单。
- 生成报价单图片。

UI 调整：

- 顶部改为正式报价单头部，突出 `CNDES 德赛`。
- 若不含运费，使用大总价卡突出最终含税价和不含税价。
- 若含运费，保留快运/物流两张对比卡，但卡片更高级、信息更清晰。
- 产品明细仍可横向承载原数据，不改字段。
- 复制和生成图片按钮改为主次按钮组合，方便业务转发。

### 申请页

申请页保留公司名称、联系人、手机号、申请说明、隐私授权流程。

UI 调整：

- 顶部强化品牌和用途说明。
- 表单卡片统一为商务高级风。
- 输入框更轻、更圆润。
- 隐私弹窗保持原文和交互，但视觉统一，确认按钮使用品牌蓝。

### 审核中页

审核中页保留刷新状态和联系管理员。

UI 调整：

- 使用品牌化等待卡片，减少 emoji 装饰。
- 两个按钮形成主次关系：刷新状态为主，联系管理员为次。

### 后台申请管理页

后台页保留申请列表、刷新、同意、拒绝。

UI 调整：

- 顶部改为管理控制台风格，显示申请数量。
- 申请卡片信息层级更清晰：公司名、联系人、手机号、时间、状态。
- 状态标签统一为浅底色胶囊。
- 同意、拒绝按钮保持清晰，但拒绝按钮降低视觉重量，避免误点。

## 非目标

- 不修改产品数据、价格、重量、折扣、税率、运费规则。
- 不修改云函数接口和权限判断逻辑。
- 不新增登录、客户管理、订单管理等新功能。
- 不改变报价单复制内容和图片生成的数据来源；如需要优化生成图片样式，作为后续单独任务处理。

## 验证方式

1. 静态检查所有 WXML/WXSS 是否能被微信小程序语法接受。
2. 重点比对报价页和报价结果页绑定字段，确认没有删除现有事件和数据绑定。
3. 检查申请页隐私弹窗、后台审批按钮、审核中刷新按钮仍保留原事件。
4. 如本地工具允许，打开微信开发者工具进行视觉检查和基础点击流程验证。
