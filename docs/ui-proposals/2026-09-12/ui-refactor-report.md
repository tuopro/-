## 3. 新增 UI 行为

- 搜索输入时显示候选；清空和取消只清理搜索界面，清单不受影响。
- 支持手动选全量高度和宽度；不会因参考图只展示几个尺寸而减少选项。
- “尺寸怎么看”解释高度在前、宽度在后，选中后明确显示“高 60 × 宽 40 mm”。
- 搜索选中后收起高宽按钮，展示当前规格与“更换规格”；齿形、颜色、米数或定长输入继续沿用原逻辑。
- 清单保留原数量失焦提交、删除、折扣与汇率事件。明细标清“原价小计”“产品折后”“不含税”。
- 配送卡解释送货上门、网点自提、不计运费。未配置运价显示“暂未配置”；不计运费时其他卡显示“选择后计算”，不会把未计算解释为零运费。
- 固定汇总使用已有总价字段；搜索和软键盘展开期间收起底部固定区域。模拟器已检查输入焦点、滚动和底部栏收起/恢复；Mac 模拟器不显示手机软键盘，真实手机上的键盘像素遮挡仍建议点验。
- 确认页默认突出当前配送对应的合计，其他已有配送报价仍能展开查看。
- “修改清单”“修改配送”返回原报价页面，定位对应区域；不重建清单。
- 定长仍只提供原来可选的快运；FOB 客户确认页仍只显示英文美元，不暴露内部人民币、折扣、汇率及分摊信息。

最近使用、三模式独立草稿、删除撤销等旧方案建议没有实施；原来的模式切换清空清单行为保持。

## 4. 规格搜索实现

唯一来源为原 `data/products.js`，包含 66 个规格、11 种高度。新工具仅输出显示字段：规格键、高、宽、规格文字、尺寸说明、有效齿形说明，不输出价格、重量或产品对象。

流程：

`输入 → 规范常见分隔符 → 读取现有规格 → 展示候选 → 点击候选 → 原 onHeightTap → 原 onWidthTap → 原齿形/颜色/数量/添加逻辑`。

| 输入 | 结果 |
| --- | --- |
| 6040、60×40、60x40、60*40、60 40 | 高 60 × 宽 40 mm |
| 4060 | 高 40 × 宽 60 mm，独立规格 |
| 100100、100120 | 根据现有规格键匹配，未按固定两位数切分 |
| 40 等部分数字 | 展示候选，高度匹配优先；必须由用户点击 |
| 6041、60×41 等不存在的完整规格 | 未找到该规格，提供手选；不推荐或选中近似规格 |

输入和清空不会改变当前选品或清单。点击还会校验目标属于当前候选；未匹配的点击不触发选品。高宽可能产生拼接歧义时保留多个候选，由用户选择。
